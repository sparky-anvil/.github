## 🔥 About

**Sparky Anvil** is a workshop where ideas are heated, hammered and shaped into working software.

Here I build pet projects on the JVM together with AI tools: from quick experiments and utilities
to full-fledged applications. AI acts as the hammer, a fast and tireless assistant,
while design decisions, code review and final responsibility stay with the human at the anvil.

## ⚙️ What happens in the forge

- 🧪 **Experiments** — trying new libraries, frameworks and language features
- 🛠️ **Tools & utilities** — small programs that solve real everyday problems
- 🚀 **Applications** — backend services, CLI tools, desktop and mobile apps
- 🤖 **AI-driven development** — exploring how far AI-assisted coding can go in real projects

## 📐 Principles

1. **Human in charge** — AI suggests, a human decides. Every line is reviewed.
2. **Working over perfect** — ship something small, then improve it.
3. **Tested and readable** — generated code must be as clean as handwritten.
4. **Learn by building** — every project is a chance to master something new.
5. **Open by default** — code, mistakes and lessons are shared publicly.
